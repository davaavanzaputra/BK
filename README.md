# RUANG AMAN — People Pleasing & Personal Boundaries

Website edukasi interaktif berbahasa Indonesia tentang people pleasing dan personal boundaries.

## Fitur
- Responsive: HP, tablet, laptop/desktop.
- Tidak membutuhkan framework atau instalasi.
- Tema terang/gelap dengan penyimpanan preferensi.
- Reading progress bar.
- Accordion penjelasan.
- Interaktif kategori personal boundaries.
- Tombol salin boundary scripts.
- Self-check 6 pertanyaan (refleksi, bukan diagnosis).
- Scenario Lab dengan feedback.
- Boundary Builder untuk membuat contoh kalimat.
- Kartu Myth / Reality.
- Mini check-in kebutuhan.
- Navigasi mobile.

## Cara membuka
1. Ekstrak ZIP.
2. Buka `index.html` di browser.

Semua aset utama sudah dibuat lokal agar website tetap tampil tanpa CDN/font eksternal.
